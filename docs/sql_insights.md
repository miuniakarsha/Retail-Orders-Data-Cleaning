\# SQL Analysis Insights



\## Objective



The objective of this phase is to analyze the cleaned retail orders dataset using SQL queries.



The cleaned data was loaded into a SQLite database and queried using business-focused SQL questions.



\## Key SQL Analysis Areas



1\. Total orders, total revenue, and average order value

2\. Orders by order status

3\. Revenue by product

4\. Payment method performance

5\. Referral source performance

6\. Coupon usage comparison

7\. Monthly revenue trend

8\. Top customers by revenue



\## Why This Phase Is Important



This phase proves that the cleaned dataset is ready for business analysis.



Instead of only preparing the data, SQL analysis helps convert the cleaned data into useful business information.



\## Dashboard Preparation



The SQL outputs from this phase will be used to decide what visuals should be included in the Power BI dashboard.



Suggested dashboard visuals:



| SQL Output | Power BI Visual |

|---|---|

| Total orders | KPI Card |

| Total revenue | KPI Card |

| Average order value | KPI Card |

| Orders by status | Bar chart or donut chart |

| Revenue by product | Bar chart |

| Payment method analysis | Bar chart or pie chart |

| Referral source analysis | Bar chart |

| Coupon usage | Donut chart |

| Monthly revenue trend | Line chart |

| Top customers | Table |
